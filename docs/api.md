# API Blueprint

Planned REST API areas:

- `/api/auth`
- `/api/profile`
- `/api/projects`
- `/api/skills`
- `/api/education`
- `/api/experience`
- `/api/achievements`
- `/api/certificates`
- `/api/media`
- `/api/social-links`
- `/api/cv`
- `/api/settings`

Public read endpoints and protected admin write endpoints will be separated.
